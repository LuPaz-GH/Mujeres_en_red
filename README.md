# Mujeres en Red

Nuevo sitio web de la Fundación Mujeres en Red (mujeresenred.com.ar).

```
MUJERESENRED/
├── frontend/   ← la web en React (diseño, páginas, animaciones 3D)
└── backend/    ← WordPress como fuente del contenido + futuro código de servidor (PHP)
```

- Para trabajar en la web: ver [frontend/README.md](frontend/README.md).
- Para entender de dónde salen los datos y cómo se publica: ver [backend/README.md](backend/README.md).

Levantar la web en la compu:

```bash
cd frontend
npm install      # solo la primera vez
npm run dev
```
